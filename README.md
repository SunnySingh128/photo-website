# 🖼️ Photo Website – Text to Image Generator

This is a **frontend-only web application** that allows users to **type text prompts** and receive images from an external **API**. It is built with **HTML, CSS, and JavaScript (Vanilla JS)** without using any frontend frameworks like React.

---

## 📌 **Project Description**

✔️ Users can type any **text prompt**  
✔️ App calls an **AI image API** or image search API  
✔️ Displays generated or fetched images instantly  
✔️ Clean and responsive UI with HTML and CSS only

---

## ⚙️ **Features**

✅ Simple and intuitive user interface  
✅ Uses **fetch API** to call external image services  
✅ Fully responsive design  
✅ Built with pure **HTML, CSS, JS (no React)**  
✅ Easy to integrate with APIs like Unsplash, Pexels, or Stability AI
